# EndeavourOS dotfiles
My personalized configuartion files for EndeavourOS including Alacritty, Waybar, hyprland & more. 

> ⚠️ **This repository is actively being developed**: This is mainly a way for me to save, and document my experiments to help me learn from my mistakes.

## Prerequisites
Make sure you've got at least:
- **Git** ≥ 2.0
- **Stow** (or any other symlink manager like `yadm/chezmoio (?)`)
- **Fish Shell** ≥ 4 (anything over 3.1 will probably work)
- **Alacritty**
- **Waybar**
- **Hyprland**
- Also use neofetch, its very pretty :p
